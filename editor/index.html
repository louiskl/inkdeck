InkDeck Editor

Pages

On the device, the page-turn keys (or a swipe) switch pages.

Widgets on this page

    Drag to reorder (in the list or the preview). Widgets fill the grid in order, starting top left.

    General

    “system” uses the device clock’s zone (on some Kindles that is UTC). Other zones: pick one above or enter a fixed offset like +09:00.

    Home Assistant (optional)

    Home Assistant → your profile → Security → Long-lived access tokens. The token is only written into your config.json – it never leaves your browser otherwise.

    Bridge (optional, only for the Spotify widget)

    Runs on any computer in your network: python3 inkdeck_bridge.py prints the address. Everything else works without it.

    This is how the page is laid out on a 600 × 800 screen. Drop a tile onto another to swap them. Click a tile to edit its settings.

    Get it onto your device

    1. Click Save config.json.
    2. Connect your e-reader via USB and copy the file into the inkdeck folder (replace the old one).
    3. On the device in InkDeck: Menu key → Reload configuration.
